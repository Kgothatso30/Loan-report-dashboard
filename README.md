# 🏦 Loan Report Dashboard

## 📋 Project Overview

This project presents a comprehensive Loan Report Dashboard designed to analyze loan distribution, applicant income, and borrower characteristics. It transforms raw financial data into meaningful insights through clear and interactive visualizations.

**The Problem:** Financial institutions need to understand loan distribution patterns, borrower profiles, and approval factors to make better lending decisions.

**The Solution:** An interactive dashboard providing loan amount analysis, income patterns, credit score distribution, and borrower demographics.

## 🔍 Key Insights

| Insight | Finding |
|---------|---------|
| **Top Loan Purpose** | Home loans drive the highest loan amounts |
| **Income Relationship** | Higher income correlates with larger loan amounts |
| **Credit Score Impact** | Approved loans have higher average credit scores |
| **Employment Type** | Salaried individuals receive higher average loans |
